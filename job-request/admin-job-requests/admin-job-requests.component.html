Job Requests Management

This page allows administrators to manage customer job requests through their entire lifecycle - from submission to quotation.

Key Features

Status Tracking

  • Pending - New requests awaiting review
  • Accepted - Approved requests ready for quotation
  • Rejected - Declined requests

Search & Filter

Quickly find job requests by:

  • Request ID
  • Customer name
  • Phone number
  • Job description

Request Management

  • View Full Details - See all request information and attachments
  • Print Design Files - Output all design images
  • Accept Requests - Approve and create quotations
  • Reject Requests - Decline unsuitable requests

How to Use

Reviewing a Job Request

  1. Click the button
  2. Examine the job details and design files
  3. Verify customer information
  4. Select the appropriate customer classification

Accepting a Request

  1. After reviewing, click
  2. The quotation creation form will open automatically
  3. Complete the quotation details
  4. Submit to finalize the acceptance

Rejecting a Request

  1. Click
  2. The request will be immediately moved to "Rejected"
  3. Optionally notify the customer about the rejection

Printing Design Files

  1. While viewing a request, click
  2. A new window will open with all design images
  3. Use your browser's print function to output the files

Troubleshooting

Can't accept request? Ensure you've selected a customer classification first

Missing design files? Verify the customer uploaded attachments

Status not updating? Refresh the page or check your connection

For further assistance, contact your system administrator.
