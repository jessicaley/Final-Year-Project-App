Stock Management Help Center

Stock Inventory System

This page allows you to monitor and manage all inventory items categorized by stock levels, with tools for creating, updating, and bulk importing/exporting stock data.

Key Features

Stock Level Tracking

  • Low Stock (<50) - Items needing urgent replenishment
  • Medium Stock (50-249) - Adequate but monitor closely
  • High Stock (250+) - Well-stocked items
  • Critical Level (≤10) - Highlighted with warning icon

Search & Filter

Quickly find inventory items by:

  • Stock ID
  • Item name or description
  • Material type
  • Category
  • Stock level range

Bulk Operations

  • Export to Excel - Download current inventory data
  • Import from Excel - Bulk update stock levels
  • Create New Items - Add individual stock entries
  • Update Existing - Modify stock details and quantities

How to Use

Viewing Stock Details

  1. Click the action button
  2. The detailed stock view will show complete item information
  3. Review all specifications, history, and related data
  4. Click Back to Stock to return to the list

Creating New Stock Items

  1. Click the button in any tab
  2. Fill in all required item details
  3. Set the initial stock level
  4. Click Submit to add to inventory

Updating Stock Items

  1. Click the action button
  2. Modify any fields as needed (quantity, details, etc.)
  3. Click Update to save changes
  4. Changes will reflect immediately in the appropriate stock level tab

Importing/Exporting Data

  1. Export: Click to download current data
  2. Import: Click and select your Excel file
  3. The system will validate and process the import
  4. Check the status alert for results

Troubleshooting

Import failed? Ensure your Excel file matches the required format

Can't update stock? Verify you have proper permissions

Item not showing? Check if it's filtered or in a different stock level tab

Critical items not highlighted? Refresh the page to ensure latest data

For further assistance, contact your inventory system administrator.
